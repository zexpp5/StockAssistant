# 政策大事雷达（2026-07-21）

**触发**：用户「像这种提前就有新闻利好的大动作，你是不是应该帮我盯着，让我提前关注」。
实证：7-13 消费"十五五"规划、7-17 习AI大会、7-19 国新500亿增持 —— 全是公开新闻，
A股 7-21 才全面爆发（科创50 +10.7%）。中间 1-3 天关注窗口，系统本该扫到并提醒。

## 0. 目标与红线

- **目标**：每晚扫权威政策源，识别「国家级、可能影响市场方向的大动作」，高门槛推飞书。
- **红线**：宁可漏报不滥报（用户已嫌卡片多）。提醒关注 ≠ 建议买入（advisory）。
- **诚实边界**：这是「第一时间提醒」不是「提前知道」；新闻→涨跌映射会出错。

缺的是稳定的第二源。第二源（财新/国务院政策库）待找到可靠接口后 P2 补。

## 2. 打分规则（core/policy_signals.py，纯函数单测锁）

三层关键词，高门槛：`score>=4 且 主体+动作+方向 三者齐全`：
- **主体**（谁说的，2分）：中央/国务院/央行/证监会/国家队… 级别不够不算
- **动作**（干了什么，2分）：批复/印发/降准/增持/万亿/领导人站台… 表态不算要真动作
- **方向**（利好谁，≤2分）：映射到可交易受益方向；货币宽松/稳市/国家队买入兜底给「大盘」
- **排除层**：GDP报数、宣传专栏(新思想引领新征程)、外事礼仪、媒体评价/央视快评 → 直接挡

「国内联播快讯」聚合条目按句拆开逐句打分（真政策常埋正文）。

## 4. 出口

- 每晚 20:10 launchd 跑（新闻联播 19:30 播完后），命中新信号推飞书橙卡。
- 去重：`data/policy_radar_log.jsonl` 按标题指纹，同一条只推一次。
- 无信号不推（宁漏勿滥）。产物 `data/latest/policy_radar.json` 供 dashboard 以后接。

## 5. 边界

- 关键词启发式，会有漏/误；高门槛偏向「漏」而非「滥」。
- 主源单一（联播），电视级以外的政策/市场动作可能漏，见 §1 缺口。
- 提醒的是「关注方向」不是「买入标的」；具体买什么、贵不贵仍需另行研究 + 用户拍板。
