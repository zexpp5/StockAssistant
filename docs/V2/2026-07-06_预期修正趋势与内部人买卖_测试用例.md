# 预期修正趋势 + 内部人买卖展示测试用例

> 对应实施方案：`docs/V2/2026-07-06_预期修正趋势与内部人买卖_实施方案.md`

## 一、单测

| 模块 | 用例 | 预期 |
|---|---|---|
| `revision_trend` | 90 天多条目标价上调 | `direction=上调中`，行文显示“分析师风向” |
| `revision_trend` | 90 天多条目标价下调 | `direction=下调中`，供前端转橙 |
| `revision_trend` | 上调/下调各一条 | `direction=分歧` |
| `revision_trend` | 只有维持或空数据 | `direction=平静`，显示“90 天无修正记录” |
| `insider_summary` | 30 天多笔买入 | `net_direction=净买入` |
| `insider_summary` | 30 天多笔卖出 | `net_direction=净卖出`，供前端转橙 |
| `insider_summary` | 买卖笔数相等 | `net_direction=平静` |
| `insider_summary` | 窗口内无申报 | 显示“30 天无申报” |

## 二、集成验收

| 验收点 | 命令/检查 | 预期 |
|---|---|---|
| 严选 JSON 字段 | 跑 `scripts/tools/build_dual_track_ranking.py` 后查 `data/latest/daily_strict_picks.json` | 每只 pick 有 `revision_trend`、`revision_line`、`insider`、`insider_line` |
| 严选卡展示 | 跑 `./build_dashboard.sh` 后打开 `stock_dashboard.html#discovery` | 每张严选卡有“分析师风向”和“内部人”两行 |
| 人话文案 | 页面文本搜索 | 严选卡不出现 `momentum` / `IC` 术语 |
| 橙色告警态 | 构造/使用含 `下调中` 或 `净卖出` 的 pick | 对应行使用 `text-amber-700` |
| 卖出免责 | 检查内部人行 `title` | 含“卖出常见于报税/行权，≠看空” |
| 只读边界 | `git diff` / 代码搜索 | 不新增写 `watchlist`、真实持仓或打分公式逻辑 |
