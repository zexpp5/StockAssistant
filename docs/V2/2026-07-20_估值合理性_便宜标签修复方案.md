# 严选估值合理性修复（2026-07-20）

**触发**：用户指出「COHR 市盈率 130 多还推荐？」→ 系统把 trailing PE 131、一年涨 179% 的票标成「🟢便宜」，明显不合理。用户「我想让系统的推荐合理，现在明显不合理」。

## 0. 诊断（根因不是"标错一只"，是缺一整类信号）

系统所有"贵/便宜"信号都是**相对**的，没有一个看**绝对市盈率**：
- `buy_zone` 的「便宜」唯一定义 = 现价 < 分析师目标价 × 0.70。分析师目标价高，再贵都标便宜。
- `expectation_meter` 看目标价消耗/PEG/一年涨幅/周期顶，**唯独不吃 trailing PE**。COHR 涨幅 179% < 200% 阈值 → 只 tier 1，PEG 0.92 低 → tier 0 → 灯是 🟢。
- 结果：131 倍 PE 的成长股从两个信号的洞里同时漏出，被标「🟢便宜」。

数据佐证（美股宇宙 n≈118）：trailing PE 中位 42 / 75 分位 64 / 90 分位 125。COHR 131 = 最贵 10%，**真贵**。

## 1. 铁律：只警示，不剔除（血泪教训）

`feedback_backtest_gates_before_adding`（MU 反验）：对估值做**剔除闸**会在 $285 踢掉后面还有 3 倍的美光。
→ 本次**绝不加剔除闸**，只做两件：①给预期灯补"绝对估值"分量（红灯更准）②把 buy_zone 的「便宜」标签说老实。票照样能进严选，只是标签不再骗人。

MU 单独说明：MU trailing PE 只有 19（看着便宜），但一年涨 642% + forward PE 5.6 = **周期股顶部**，靠已有的「周期顶警示」抓（不靠新的 trailing PE 分量）。两条路径分工，互不误伤。

## 2. 预注册阈值（数据驱动，不拍脑袋；改动须走文档）

| 信号 | 切点 | 依据 |
|---|---|---|
| trailing PE 极高 | ≥ 100 → tier 2（红） | 逼近 90 分位(125)，全宇宙最贵 10% |
| trailing PE 偏高 | ≥ 64 → tier 1（黄） | 75 分位 |
| buy_zone「便宜」降级 | trailing PE ≥ 100 或（≥64 且一年涨≥100%） | 高估值 + 涨幅共振才降级，避免误伤真便宜 |

## 3. 改动（照做）

- [x] **P1** `expectation_meter.py`：加 `trailing_pe` 入参 + 分量⑤「绝对估值」(tier 同上)，计入 score/max_score/reasons。缺值跳过不硬凑。
- [x] **P2** `buy_zone.py`：多取 `trailing_pe`+`one_year_pct`；加 `valuation_caution` 字段；`format_line`/图标：position=="便宜" 且 caution → 显示「🟡低于目标价·但估值高」而非「🟢便宜」。position 原值(便宜/区间内/偏贵)保留供逻辑，仅显示层说老实。
- [x] **P3** 严选生成器把 trailing_pe 喂给 meter；卡片/早报随单一来源自动更新。
- [x] **P4** 单测：meter 新分量(COHR 型高 PE 红、MU 型低 PE 不误伤)+ buy_zone 降级(COHR 便宜→估值高警示、QCOM 真便宜不降级)。
- [x] **P5** 全宇宙眼验：跑当前严选，确认 COHR 不再「便宜」、MU 显周期顶、TSM/NVDA/QCOM 不误伤。
