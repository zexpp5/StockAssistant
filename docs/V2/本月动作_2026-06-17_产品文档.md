# 本月动作 产品文档

日期：2026-06-17

产品位置：`AI 工作台 → 本月动作`

## 一、产品定位

`本月动作` 是 AI 工作台里的月度收敛页。

它把 `AI 推荐`、`AI 组合方案`、`买入区间`、`策略验证状态`、`真实持仓体检` 压缩成一张只读动作清单，回答三个问题：

- 这个月如果只看一次系统，哪些候选可以小笔研究性加仓？
- 真实持仓里有没有比“继续买”更优先的集中度纠偏？
- 哪些候选因为偏贵、过热、同赛道重复、超配或证据不足，本月明确不买？

它不是新的推荐池，不是交易系统，不是持仓编辑器，也不是新的策略版本。

## 二、目标用户与场景

目标用户：
- 已经有真实持仓，希望降低每天盯盘和频繁调仓负担的用户。
- 想用 AI 推荐做研究候选，但不想把系统当成自动买卖信号的用户。
- 需要每月固定一次检查“可以买什么、先别买什么、该不该纠偏”的用户。

典型场景：
- 每月固定日期打开页面，决定当月是否小笔加仓。
- 持仓集中度过高时，优先看到纠偏提醒，而不是继续新增买入。
- 市场或策略验证不达标时，页面明确提示“现金等待”或“研究候选，不是已证明买点”。

## 三、核心原则

1. 只读：页面只给 advisory，不自动交易，不写真实持仓。
2. 收敛：每月最多给 3 个可加仓候选；没有合适标的时明确写“现金等待”。
3. 先纠偏后买入：单只超配、同赛道过度集中、策略验证不足的优先级高于新增买入。
4. 不伪装实时：价格只能叫“参考价”，必须展示交易日或明确标注“收盘参考 / 非实时”。
5. 不新增股票池：候选只能来自已有 AI 推荐 / AI 组合方案 / 真实持仓体检，不单独生成新池子。

## 四、数据来源

| 数据 | 用途 | 边界 |
| --- | --- | --- |
| AI 推荐结果 | 提供候选股票、推荐批次和推荐时间 | 不改变推荐排序 |
| AI 组合方案 | 提供模型目标权重和配置参考 | 不等于真实持仓 |
| `data/latest/recommendation_readiness_check.json` | 判断策略验证是否达标 | 未达标时必须从严 |
| `BUY_ZONES` | 提供买入区间和参考价 | 参考价必须有交易日或非实时口径 |
| `data/latest/real_holding_review.json` | 读取真实持仓集中度、纪律线、风险红旗 | 只读，不写持仓 |

## 五、页面结构

### 1. 策略验证状态

展示当前推荐策略是否达到真钱级验证。

未达标时必须用大白话提示：
- 当前只是研究候选。
- 不是已证明买点。
- 单只上限和总上限必须从严。

### 2. 当前 / 动作后快照

展示当前持仓集中度，以及执行本月建议动作后的变化。

重点显示：
- 当前最大单只持仓占比。
- 本月新增动作是否真的能降低集中度。
- 只靠新钱稀释是否有效。

如果类似 `GOOGL` 这种单只已经超过 50%，页面必须提示“严重集中”，不能只写“新钱稀释”。

### 3. 赛道护栏

默认规则：
- 单一赛道暴露上限：15%。
- 同一赛道本月最多保留 1 个新增动作。
- 多只候选都属于同一主题时，只留下优先级最高的一只，其余进入“不买原因”。

### 4. 可加仓

最多展示 3 只。

每只必须展示：
- 股票代码 / 名称。
- 所属赛道。
- 本月金额上限。
- 参考价和对应交易日。
- 推荐时间或推荐批次。
- 为什么可以买。
- 为什么不能买更多。

### 5. 纠偏 / 不再加

触发规则：
- 单只持仓超过 25%：本月不再加。
- 单只持仓超过 40%：给出主动季度纠偏参考。
- 单只持仓超过 50%：标记严重集中。

纠偏措辞必须保持 advisory：
- 可以写“建议季度复盘时减至某仓位以内”。
- 不允许自动生成真实卖出单。
- 不允许自动修改真实持仓。

### 6. 本月不买原因

必须透明展示被过滤的候选。

常见原因：
- 偏贵或高于买入区间。
- 短期过热。
- 同赛道重复下注。
- 已经持仓超配。
- 策略验证未达标。
- 缺少买入区间。
- 缺少参考价交易日。

## 六、金额与仓位规则

默认建议：
- 未达到真钱级验证时，单只只允许小仓试探。
- 新增买入总额必须受月度预算控制。
- 单只新增后不得突破单股上限。
- 单赛道新增后不得突破主题上限。

页面必须明确“为什么不买更多”，避免用户把候选清单误读成满仓买入信号。

## 七、硬边界

- 不写 `watchlist`。
- 不写真实持仓。
- 不自动交易。
- 不生成新的股票池。
- 不改变 AI 推荐排序。
- 不改变 AI 组合方案。
- 不静默修改策略版本。
- 不输出“实时价格”。
- 不把模型建议包装成确定性投资建议。

## 八、失败与降级

| 情况 | 页面表现 |
| --- | --- |
| 缺少策略验证状态 | 降级为只读研究参考，不输出强买入 |
| 缺少买入区间 | 该标的不进入可加仓 |
| 缺少参考价交易日 | 标为“收盘参考 / 非实时”，不得裸展示价格 |
| 真实持仓体检缺失 | 不输出纠偏结论，只提示数据不足 |
| 同赛道候选过多 | 只保留 1 只，其余写入不买原因 |
| 无合适候选 | 明确写“本月不买，现金等待” |

## 九、免责口径

页面必须保留明确口径：

> 本页为研究辅助和纪律提醒，不构成投资建议；页面不会自动交易，也不会自动修改真实持仓。
